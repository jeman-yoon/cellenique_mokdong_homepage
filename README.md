# 세레니끄 목동점 홈페이지

코리아나 화장품 전문 에스테틱 **세레니끄 목동점**(CELLENIQUE by Coreana) 소개 페이지입니다.
방문자 대부분이 휴대폰으로 보기 때문에 모바일 화면을 기준으로 만들었습니다.

- `index.html` — 페이지 전체 (HTML · CSS · 자바스크립트가 한 파일에 들어 있음)
- `img/` — 사진 · 포스터 · 제품 이미지
- `video/` — 히어로 영상(`hero-canva.mp4`), 매장 소개 영상(`cellenique-mokdong.mp4`)

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요 없습니다.
